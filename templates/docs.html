Getting Started

Create your first AI chatbot in 5 minutes

Step 1: Create a Bot

Go to the Dashboard and click + New Bot. Choose a template or start from scratch. Give your bot a name and select your LLM provider.

Step 2: Upload Knowledge

Navigate to the Knowledge tab. Upload files (PDF, DOCX, Excel, CSV, JSON, TXT, HTML) or paste a website URL. The system automatically parses, chunks, and embeds your content.

Step 3: Test Your Bot

Switch to the Test Chat tab and ask questions about your uploaded content. The bot will answer using only the information from your documents.

Step 4: Deploy

Go to the Deploy tab and copy the embed code. Add it to your website:

<script src="https://yourdomain.com/widget.js"
  data-bot-id="your-bot-id"
  data-api-url="https://yourdomain.com"></script>

Supported Data Sources

All file types and databases you can connect

File Uploads

  • PDF — Parsed page by page with text extraction
  • DOCX — Microsoft Word documents with heading detection
  • CSV/Excel — Spreadsheets converted to structured text
  • JSON — Nested JSON flattened to key-value pairs
  • TXT/MD — Plain text and Markdown files
  • HTML — Web pages with automatic tag cleanup

URL Crawling

Paste any URL and NeuralDesk will crawl the page, extract the main content (removing navigation, footer, scripts), and add it to your bot's knowledge.

Database Connectors

  • MySQL — Connect with host, port, database, username, password
  • MongoDB — Connect to any MongoDB instance
  • SQLite — Upload a .db file directly

LLM Providers

Configure your AI model

Ollama (Free, Local)

Run AI models on your own machine. No API key needed. Install from ollama.ai and pull a model: ollama pull gemma3:latest

OpenAI

Models: gpt-4o, gpt-4o-mini, gpt-4-turbo. Get your key from platform.openai.com

Google Gemini

Models: gemini-2.0-flash, gemini-2.0-pro. Free tier available at aistudio.google.com

Groq (Fast & Free tier)

Models: llama-3.1-70b, mixtral-8x7b. Ultra-fast inference. Key from console.groq.com

Anthropic Claude

Models: claude-sonnet, claude-haiku. Key from console.anthropic.com

Widget Customization

Customize your chatbot's appearance

Bot Settings

  • Persona Name — The name shown in the chat header
  • Welcome Message — First message visitors see
  • System Prompt — Instructions that shape how the bot responds
  • Primary Color — Widget accent color (default: #6366f1)

Suggested Questions

Auto-generated from your uploaded content. When you upload a new file, 3 suggested questions are created automatically based on the document.

📊

Analytics & Leads

Track performance and capture visitors

Analytics Dashboard

  • Total Conversations — How many chat sessions
  • Total Messages — Total messages exchanged
  • Satisfaction — Based on thumbs up/down feedback
  • Unanswered Questions — Topics your bot couldn't answer

Lead Capture

The widget collects visitor name and email before chat starts. View all captured leads in the Analytics tab. Use this data to follow up with potential customers.

Improving Your Bot

Check the Unanswered Questions list regularly. Upload more content to cover those topics. Your bot gets smarter with every document you add.

API Reference

REST API endpoints for developers

Authentication

POST /api/auth/signup   { email, password, name }
POST /api/auth/login    { email, password }
→ Returns: { access_token, user_id, name }

Bots

POST   /api/bots              Create bot
GET    /api/bots              List all bots
GET    /api/bots/:id          Get bot details
PUT    /api/bots/:id          Update bot
DELETE /api/bots/:id          Delete bot

Knowledge

POST   /api/bots/:id/knowledge/file      Upload file
POST   /api/bots/:id/knowledge/url       Add URL
POST   /api/bots/:id/knowledge/database  Connect DB
GET    /api/bots/:id/knowledge           List sources
DELETE /api/bots/:id/knowledge/:sid      Delete source

Chat

POST /api/v1/chat    { bot_id, message, session_id }
→ Returns: { answer, sources, confidence }
